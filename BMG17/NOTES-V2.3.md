# BMG 2.3 — séparation budget études / marché sous-traitant

- Les codes ST sont créés exclusivement dans Budget évolution, avec leur budget études.
- La fiche correspondante apparaît automatiquement dans ST avec un marché engagé initial à 0 € et un prorata par défaut à 2 %, à renseigner indépendamment.
- Le bouton de création de marché ST depuis ST est remplacé par un lien vers Budget évolution.
- Le texte d’aide de ST est réécrit dans un style professionnel.
- Les marchés déjà enregistrés dans les sauvegardes existantes sont conservés tels quels. Vérifier manuellement les marchés historiques éventuellement initialisés à partir du budget études.
- Le prorata reste calculé sur le marché initial + OM + travaux à régulariser, hors provisions.
