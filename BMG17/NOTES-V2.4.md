# BMG 2.4 – Marché ST et provisions séparés

- Budget études saisi dans Budget évolution, marché ST saisi indépendamment dans Sous-traitance.
- Marché ST actualisé = marché initial + OM + travaux à régulariser, hors provisions.
- Les provisions sont affichées distinctement comme exposition supplémentaire.
- Rapprochement RAD/factures au centime sur le marché ST actualisé hors provisions.
- Le prorata ST conserve son assiette hors provisions.
- Les données existantes sont préservées : corriger manuellement les anciens montants préremplis si nécessaire.
